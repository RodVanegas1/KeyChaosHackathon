# Bancoagrícola Hackathon — React + Vite + Docker + PWA

## Docker
```
docker compose down
docker compose up --build
```
Open http://localhost:8080

## Local
```
npm install
npm run dev
```

This version is intentionally simple and mobile-first. No personal names, real account data, phone status bar, or transaction details are included. The four quick-action buttons are visual-only placeholders for the backend team.

Service worker is intentionally minimal and does not pre-cache the app shell, avoiding stale blank-screen caches during hackathon iteration.
